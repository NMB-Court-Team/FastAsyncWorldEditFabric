# 项目规范与要求

本节介绍本项目的项目规范。  
本项目英文名为***Fast Async World Edit Fabric***，简称***FAWE Fabric***，基于项目[FastAsyncWorldEdit](https://github.com/IntellectualSites/FastAsyncWorldEdit)编写一份Fabric版本。  
FastAsyncWorldEdit项目已经下载到`FastAsyncWorldEdit-main`目录下，该目录仅本地排除，Agent进行迁移任务时可以直接参考这个目录中的代码。  

由于FAWE本身是基于World Edit编写的，因此本项目最好也基于Fabric版本的World Edit编写，然后使用FAWE的原理对World Edit进行优化。

## I18N

本项目需要做I18N，目前只需要支持简体中文`zh_cn`和英文（美国）`en_us`两种。  
翻译键的命名优先尊重原版Minecraft的命名规则，如原版没有，则应该在开头加上`fastasyncworldedit.`的前缀，然后参考原版Minecraft的命名规则进行命名。

## 其他

创建`Identifier`时，优先使用`FastAsyncWorldEditMain.id`方法来创建。  
优先使用`FastAsyncWorldEditMain.LOGGER`来打印日志，日志必须使用英文编写。  
函数文档、类文档等文档使用中文编写。  
在多线程场合下，建议使用Kotlin协程编写。
